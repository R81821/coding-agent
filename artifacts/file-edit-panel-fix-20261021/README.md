# 文件写入与逐次代码变更面板修复

验证日期：2026-10-21。

## 原因与修复

- 原来提示文案和前端分类认识 `write_file`，工具注册表却没有实际实现。现在提供真实 UTF-8 文件写入工具，并对内置默认配置做一次迁移；自定义和只读配置不扩大工具权限。
- 原来编辑事件被折叠进命令组，展开后主要展示原始 JSON。现在本地 `write_file`、`patch`、`apply_patch` 各自保留时间线条目，成功回执默认展开为代码变更小面板。
- 面板显示文件名、语言、可用的字节大小与准确增删行数，提供复制差异、展开收起和内部横向滚动。覆盖编辑以红色删除、绿色新增显示；失败、未完成、未变更和截断记录分别表达真实状态。
- 补丁回执保存实际规范化后的有界差异；多文件预览截断时仍保留所有实际变更路径，无法完整统计时明确标注。
- 写入默认不覆盖，覆盖须显式指定；可用 `expectedSha256` 拒绝过期内容。保留工作区路径和权限检查，并接入实际文件变化、修订号及验证失效判断。

旧的纯终端日志没有逐次文件差异回执，不能还原为同样的编辑面板。重启更新后的桌面端和 daemon 后，新产生的文件工具记录会使用新样式。
