# 长期记忆与项目知识

入口：工作台工具 → 记忆。

## 默认行为

新 Profile 默认读取会话、项目和全局三种记忆。启动时，旧版默认配置（会话 + 项目）会一次性迁移为三种范围；自定义范围、已停用配置和迁移后主动关闭的全局开关保持原样。

任务结束后，运行时使用当前路由模型单独提炼长期知识，最多 8 条、最长 15 秒，使用剩余模型轮次和费用预算，usage 标记为 `memory`。关闭项目和全局范围后不再提炼长期候选。提炼失败或预算不足不影响已完成任务；可在记忆页手动新增。该功能不批量追溯旧对话。

提炼输入包括当前请求、已接收的补充要求、验证通过时的最终结果，以及启用范围内的已有记忆。不读取附件正文或模型内部推理。每条候选保留原文引述与运行来源；引述必须确实出现在输入中。全局自动候选只接受用户明确表达的长期个人偏好。

## 确认、维护与召回

- 自动提炼内容先成为“待确认”，点击“记住”后用于后续任务。手动“保存并记住”无冲突时立即生效。
- 相同范围的重复内容合并来源。模型会参考已有主题，尽量统一同义表述；确定性去重保留 `C` / `C++` 等符号差异。
- 同范围、同主题但不同内容会显示冲突。点击“替换旧记忆并记住”会原子地批准新内容、停用旧内容；不同项目彼此隔离。
- 修改正文、分类或范围后重新确认；可固定、设定到期时间、忽略、删除或导出。忽略、过期、被替换的内容不会因重复提炼自动恢复。
- 已批准且有效的固定记忆、偏好、规范优先召回；决策和事实按任务关键词匹配，支持中文双字索引。默认最多召回 8 条，同主题项目规则覆盖全局默认值，当前用户要求优先。
- 范围开关控制下次任务的召回和对应长期候选提炼，不删除已有记录。全局指当前本地加密数据仓库内跨项目共享，不等同于云同步或其他软件的记忆。

## 同步 AGENTS.md

选择项目会话，再点击“同步项目规范与知识”。当前项目已批准且未过期的规范进入根目录 `AGENTS.md`；决策和事实进入 `docs/agent-knowledge.md`，AGENTS.md 保留索引。一次最多同步 100 条。

先展示两个文件修改前后的完整内容，点击“应用并信任项目规范”才写入并信任本次版本。仅替换 `harness-memory` 标记之间的托管内容，保留手写部分。预览后记忆或文件发生变化会拒绝写入，写入途中出错会尽量还原本次内容；符号链接和目录联接不允许作为写入目标。

同步的记忆后来被编辑、删除、过期或替换时，运行时会停用旧的托管指令区，并继续保留手写规范。重新同步可更新磁盘内容；即使没有可同步记忆，也可同步以清除旧条目。手工编辑整个文件仍遵循现有项目规范信任机制。

## 验证

- `tests/memory-learning.test.ts`：默认迁移、去重、冲突、作用域、中文召回、模型提炼与计费。
- `tests/project-memory.test.ts`：预览、同步、失效、并发修改回滚与路径检查。
- `tests/engine.test.ts`：实际运行结束提炼，确认后在新会话召回。
- `apps/desktop/scripts/memory-ui-test.cjs`：生产渲染器及 IPC 白名单，使用隔离测试数据验证完整界面操作。
- `apps/daemon/scripts/memory-smoke.mjs`：真实后台 RPC、项目文件同步与信任、加密持久化和重启后的开关设置。

构建桌面后，在 `apps/desktop` 中运行 `node_modules/.bin/electron.cmd scripts/memory-ui-test.cjs`；运行时需清除 `ELECTRON_RUN_AS_NODE`。
