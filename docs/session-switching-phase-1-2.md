# 项目与会话切换优化：第一、二批

实施日期：2026-10-05；最终核验：2026-10-06。覆盖桌面端、Web 端、Daemon、协议与 SQLite 读取路径。

后续调整（2026-10-07）：下述预览截断及手动加载设计已由[完整内容自动加载](session-full-content.md)替代；此文保留前两批当时的实现与验证记录。

## 已落地

- 点击会话即切换选中项、项目和页面；有缓存先显示缓存，再校验最新数据。切换不取消后台任务。
- 页面加载与任务运行状态分开。会话与新任务入口不再因其他任务运行而禁用。
- 导航版本号隔离过期请求、过期错误、后台续办和事件订阅；校验期间不允许向旧会话提交任务。
- 新建会话成功后才停止原页面的事件跟随；创建失败仍继续显示原任务。删除请求晚返回时，不清空随后切换到的其他会话。
- 按会话保存草稿、任务模式与滚动位置；桌面端同时保留附件草稿。缓存和草稿只在内存中保存。
- 会话预览 LRU 上限为 6 个会话、合计 12,000,000 字节；删除、权限相关刷新和断开连接时清理缓存。
- 新增 `session.view`：按 `(created_at, id)` 游标分页，每页最多 20 轮。只返回回答预览及少量状态事件，不读取工具输出对象。回答预览最多 16,000 字符；完整回答和执行记录由用户按需加载。
- 新增 `run.eventPage`：按 sequence 读取增量事件，默认每页 100 条、上限 200 条。工具输出以延迟加载标记返回。
- 新增 `run.output`：按需读取工具输出，默认每页 16,000 字符、上限 64,000 字符。
- 桌面端和 Web 的活动会话只跟随新增事件；读完最后一页且运行结束后停止轮询。Web 不再周期性重读整个会话和所有侧栏页。
- 侧栏会话采用单条 SQL 分页查询，统计运行数量和最新状态时无需解密运行记录，仅解密返回页中的会话记录。元数据迁移在事务内执行，正文、标题和工作区路径保持加密。
- 切换工作区只刷新该工作区技能列表，不再连带刷新全部配置目录。
- 保留引擎使用的 `session.get` 完整历史语义。桌面“代码变更”页仍需完整差异证据，改为打开该页时加载。

## 验证

- 最终完整测试集：`pnpm exec vitest run --maxWorkers=2`，111 个文件、709 项测试全部通过。
- 一次与构建并行运行的整套测试中，撤销操作测试触发了 5 秒超时；单独复核耗时约 2.35 秒并通过，随后降低并发的完整测试也全部通过。未放宽测试超时或修改该测试。
- 新增 `tests/session-view.test.ts`：9 项测试通过，覆盖游标无重复、首屏读取范围、工具输出延迟解密、增量游标、删除后的访问限制、侧栏解密数量、缓存淘汰和分页合并。
- 最终相关回归：会话分页、运行历史、存储迁移、Web bridge 与执行过程组件通过。
- `pnpm typecheck`、`pnpm build` 通过；本次修改文件的 ESLint 检查及 `git diff --check` 通过。
- 浏览器实际页面验证：两会话草稿独立恢复。
- 浏览器延迟响应夹具验证通过：立即选择、后一次导航优先、缓存预览、后台刷新隔离、旧错误隔离、失败重试、静止会话无轮询、从游标继续到运行结束、断开后清空会话。
