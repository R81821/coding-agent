# 代码变更与审批展示

侧栏“代码变更”展示当前会话各轮已记录的差异，默认显示最新记录。可选择记录和文件，切换统一/并排视图，查看旧、新行号和增删行数。

数据来源：成功完成且返回 applied: true 的 patch/apply_patch；成功完成的 git_diff 中未暂存、已暂存、未跟踪文件分别显示。失败或仍待执行的补丁不会显示为已应用。每条记录独立，不累计重复快照。历史记录不是磁盘实时状态；终端写入需要后续 git_diff 才能查看。超大差异限制预览行数并标注，统计只反映展示部分；二进制和未完整读取的文件显示说明。

审批页面和请求审批弹窗共用 ApprovalContent。优先显示 content 正文，命令、标准输入、路径等其他参数分别展示，保留换行以及内容本身的花括号。内容按纯文本渲染，不执行 HTML，不改变审批请求或权限判断。

验证：类型检查、lint、桌面单元测试、桌面构建；使用隔离 userData 和虚拟 IPC 的隐藏 Electron 窗口验证文件切换、两种差异视图、经典/Kelo 主题、审批页面、弹窗和批准操作。截图与测试记录位于 .cache/code-changes；不访问真实 daemon、数据库或凭据。
