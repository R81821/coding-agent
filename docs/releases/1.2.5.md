# Harness Agent 1.2.5

将模型回复从直接显示 Markdown 源码改为解析后渲染的消息组件。原先最终回复和过程记录都使用 pre 标签，标题、列表和表格因此不能形成可视层次。

- 最终回复和过程记录支持标题、列表、引用、行内代码、任务清单和表格。
- 代码块独立显示语言标识、语法高亮和复制按钮；较宽的代码与表格可横向滚动。
- 最终回复支持复制完整 Markdown，以及切换原文和渲染视图。
- 流式输出中的未闭合代码块仍可显示，未知语言和超长代码回退到纯文本代码块。
- 外部 HTTP(S) 链接经桌面桥接打开；不执行回复中的原始 HTML，图片显示为链接。
- 包管理器声明与工作区实际使用的 pnpm 11.25.0 对齐。

验证：106 项自动测试、类型检查与 ESLint 通过。桌面交互验证覆盖历史恢复、项目分组、流式渲染、代码与原文复制、视图切换和外部链接桥接；使用隔离的测试数据，未访问用户数据库或调用模型。
