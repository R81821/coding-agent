# Harness Agent 1.4.3

本版本包含技能搜索推荐、固定版本预览、Global 安装与启用，以及对话中的技能多选。推荐任务使用当前 Profile 独立运行；下载命令只解析，不作为终端命令执行。技能正文和随附资源共同参与信任校验，对话保存选择，运行保存所用内容版本。

同时包含当前分支的内置浏览器、输入框、标题栏与菜单改进。

同版本更新：聊天和技能搜索的单次输出上限统一为 393,216 tokens，移除聊天原有的输出比例限制。类型检查、6 项相关回归测试及重新构建通过。

验证：类型检查、完整构建、75 个测试文件中的 443 项测试全部通过。包内 8 个桌面文件和 21 个后台文件与构建产物一致；后台启动、版本和技能接口冒烟测试通过。

Windows x64 安装包：`Harness-Agent-1.4.3-x64.exe`。文件大小、SHA-256 和签名状态见[发布清单](./1.4.3-manifest.json)。
