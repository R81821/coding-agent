# Harness Agent 1.3.1

修复 Agent Loop 在预算尚有余量时提前结束的问题。

- 标准新建和删除文件补丁允许 /dev/null 标记，实际越界路径仍被拒绝。
- 完成一批修改后通过显式检查点验证，避免在探测脚本创建前运行验证。
- 修复及工具自纠正次数不限；默认工具调用 128 次、模型轮次 64 轮。
- 停止卡片显示真实原因、用量、未完成事项及最近真实失败。
- 恢复运行保留修复计数，兼容以助手消息结尾的历史。
- 启动时一次性迁移 default Profile 的默认预算及修复设置；历史运行预算不重写。

修复代码通过 232 项测试、类型检查、lint 和完整构建；桌面固定数据烟测通过 34 项。
