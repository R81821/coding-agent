# Harness Agent 1.4.0-beta.1

1.4.0 批次一的预发布版本：轻量工作流成为生产默认路径，尚未包含界面与存储改造。

## 任务模式与执行影响

- 新增 `RunSpec.taskMode`（auto | analysis | change）。分析模式只读：允许读取与精确的只读 Git 查询，任意脚本被拒绝。
- 权限风险、执行影响、仓库版本三个概念分离。运行时在非只读调用前后对工作区取内容快照，只有确认的内容变化才递增版本；终端查询永不递增版本。
- 影响无法确认时保持“未确认”状态，直到一次成功的仓库复查或确认写入，不能直接声称未修改。

## 轻量工具

- 新运行不再向模型公开大型 `update_workflow`；改为 `todo`、`search_files`、`read_file`、`patch`、`terminal`、`run_verification`、`read_evidence`。
- 旧工具名称保留兼容映射，权限约束不变。
- 工具结果只返回 `evidenceId`、截断后的诊断与错误标记；抛出的失败与结构化失败返回同一信封，可用 `read_evidence` 取回。

## 上下文与压缩

- 工作预算 128K：80% 触发压缩、压至 45% 以下，并用服务端真实输入 token 校准估算。
- 先卸载过期工具内容再执行摘要；拒绝空摘要、DSML 与结构不完整摘要，回退运行时事实；单次失败不重试。
- 检查点保存压缩后的上下文；观察条目有界（旧运行 32 条、新模式 512 条）。

## 供应商

- 新增显式 `chat_completions | responses` 协议选择；DeepSeek 官方地址按无状态 Responses 处理并保留完整本地上下文。
- 私有推理只进入模型历史，不进入界面；响应 ID 在请求发出前失效，失败或取消的流不会被续接。
- 用量按主循环、摘要与评审分类统计，未知价格显示为未知而不是 0。

## 验证

- `run_verification` 支持 stdin、超时与工作目录；解释器缺少脚本时返回配置错误，不执行空验证。
- 缺失验证配置按可恢复项报告，不再中断整轮运行。

## 未包含（批次二）

- 输入区任务模式选择、执行内容指纹、桌面端“任务计划/实际修改/验证结果”分栏与缓存统计分栏。
- SQLite WAL、检查点引用化与旧库迁移。
- 安装包界面安装检查未执行；安装包未签名。
