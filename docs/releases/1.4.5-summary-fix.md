# Harness Agent 1.4.5：恢复任务时重复总结修复

修复停止后的临时“工具不可用，只生成总结”指令被保存为用户要求、在继续任务及上下文压缩后持续生效的问题。此前模型可能多次输出长结论，而运行时仍要求补充验证或评审。

- 给内部收尾指令增加明确的来源标记，只在当前总结请求中生效。
- 在正常完成、异常、快照保存和上下文压缩时隔离临时指令；结束后恢复原有工具。
- 恢复旧任务时兼容清理原有完整收尾模板，保留用户原始请求、继续说明、运行中补充消息及工具证据。
- 恢复时明确按照当前工具能力、权限和剩余计划继续。

回归覆盖恢复原任务、创建继续任务、旧会话历史、总结失败、真实用户引用和压缩期间的指令生命周期。另使用本次故障会话的只读快照确认只移除了过期指令，没有改写用户数据库。

安装包位于 `apps/desktop/release/1.4.5-summary-fix/Harness-Agent-1.4.5-x64.exe`，版本仍为 1.4.5。退出旧应用后安装此修复包生效。已经生成的重复历史消息保留；此修复不自动删除或改写历史回答。

构建校验及 SHA-256 见同目录 `release-manifest.json`。安装器未签名；未执行实际安装。
