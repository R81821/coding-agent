# Harness Agent 1.2.6

将“模型执行后统一验证”更新为有状态的 Coding Agent 工程循环。

- 修改前强制任务理解、仓库证据、工作上下文和计划／假设。
- 修改后暂停模型，先局部验证，成功后再扩大验证；失败进入诊断与假设更新。
- 验证项支持 Profile 分层配置，也支持 Agent 在本次计划中提出并经过授权执行。
- 完成门槛检查当前修改版本的验证、完整 diff、逐项需求证据与最终评审。
- 工作流随检查点恢复并持续进入模型上下文，界面显示阶段、假设和验收状态。
- 通用终端和验证执行计入工具预算；恢复后的未知执行状态要求先诊断。

流程、配置及限制见 [Agent Loop](../agent-loop.md)。
