# Harness Agent 1.2.2

修复点击“新建任务”后旧会话在侧栏消失、无法重新打开的问题。

原因：桌面界面只维护当前任务的标题和事件，新建时清空这些状态；侧栏也只渲染当前任务。运行请求和事件仍保存在加密数据库，但原先没有历史列表和恢复接口。

- 新增持久化会话历史列表，按创建时间倒序展示项目、标题和运行状态，支持加载更早的记录。
- 点击历史记录恢复原始提问、回答、工具事件、项目和 Profile；重新打开应用后仍可读取。
- 新建只清空当前视图，保留侧栏历史。发送新任务后刷新列表。
- 恢复失败时保留当前视图并显示错误；加载和轮询通过运行 ID、事件序号与视图版本避免重复消息或串入其他任务。
- 继续使用原有加密 runs/events 数据，无需迁移。历史以每次运行记录展示，不改变现有每次发送创建独立任务的语义。

验证：类型检查、lint、生产构建通过；27 个测试文件、96 项测试通过。新增数据库关闭重开、分页、IPC 边界、历史合并和事件隔离测试。

独立 Electron 界面测试使用真实构建后的渲染器与测试 IPC，验证新建保留历史、恢复成功/失败、发送新任务、刷新及重新打开记录。测试不读取用户数据库、不调用模型；数据库重启持久化另由回归测试覆盖。

复现界面测试：先运行 `pnpm build`，再用标准 Electron 可执行文件运行 `apps/desktop/scripts/history-smoke.cjs`。脚本使用隐藏窗口，将隔离配置与截图保存在工作区 `.cache` 下。
