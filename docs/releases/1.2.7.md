# Harness Agent 1.2.7

增强 Agent Loop 的证据校验、故障恢复和验证状态展示。

- 诊断必须引用本次失败或后续观察；重复失败需要新的仓库检查，更高等级需要替代假设与实验记录。
- 同一未解决故障链独立计数，新故障不再继承累计失败的升级等级。
- 验证区分 passed、failed、skipped；扩大验证支持必需、可选、禁用策略。
- 所有任务恢复后都重新获取验证与评审证据，包含只读 analysis 任务。
- 需求逐项绑定当前版本的真实观察、成功验证 ID 和完整 diff；最终评审也必须引用当前 diff。
- 新增可选风险触发的独立只读评审，受上下文、费用、轮次及时间预算限制。
- 桌面显示验证跳过原因、当前故障次数，并提供策略与修复上限配置。

证据校验并不机械证明业务语义；详细边界与配置见 [Agent Loop](../agent-loop.md)。
