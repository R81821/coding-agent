# Harness Agent 1.4.5：审核收尾与输出额度修复

修复主模型已经输出报告后，独立审核被截断或发生供应商异常，又生成第二篇长结论的问题。审核失败时保留属于当前需求与代码版本的报告，附上明确的待复核状态；工作区变化导致报告失效时，使用当前证据收尾，预算不足也不会发布过时结论。

- 保留工作流自身的审核、验证和完成条件。Profile 未启用额外审核不会关闭工作流审核，也不会新增第二次 Profile 审核请求。
- Profile 页新增单次主回答、单次审核的最大输出 token 设置，支持保存、留空默认与独立配置。配置随新运行冻结，已有运行恢复时沿用原额度。
- 主回答默认上限 393,216；审核首次自动分配 8,192～16,384。明确输出截断后最多增加额度重试一次，默认最高 32,768；每次请求受用户硬上限、模型能力和上下文余量限制，推理 token 计入额度。
- 两次审核共用 60 秒总截止时间，并分别计入轮次、用量及费用。真实审核不通过继续修复；无效 JSON、取消和其他异常不触发扩额度重试。
- 桌面最终结果按来源轮次更新同一份正文，保留审核状态；历史补载不重复追加最终报告。Web 终态待复核结果结束运行指示并显示真实状态。
- 保留前一修复包对临时停止指令生命周期及旧任务恢复的修复。

安装包位于 `apps/desktop/release/1.4.5-review-output-fix/Harness-Agent-1.4.5-x64.exe`，版本仍为 1.4.5。退出旧应用后安装，再在 Profile 页设置输出额度；保存后用于新运行。
