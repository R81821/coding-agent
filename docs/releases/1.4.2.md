# Harness Agent 1.4.2

本版加入代码变更面板，可按记录和文件查看统一或并排差异；审批内容改为提取正文显示，并统一审批、删除确认弹窗样式。

桌面布局调整为 1200×800 初始窗口，侧栏支持拖动和键盘调节并保存宽度；输入区缩小约四分之一并居中，只保留带颜色区分的 Auto、Plan、Build 模式标签。Kelo 玻璃主题改为纯白底色。

同时包含 1.4.1 之后的异步取消、并发调度、委派生命周期和 Provider 稳健性修复。63 个测试文件、372 项测试全部通过，包内桌面与 daemon 版本均为 1.4.2。Windows x64 安装包未签名，校验信息见[发布清单](./1.4.2-manifest.json)。
