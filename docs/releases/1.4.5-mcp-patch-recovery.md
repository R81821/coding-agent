## 修复行为

- MCP 恢复时保留冻结的工具描述与参数定义。新版检查点允许不改变校验语义的说明文字变化；工具参数契约、服务器版本或旧版无法确认的契约变化会隔离相关工具，并将不可用原因传给模型，本地工具可继续执行。执行工具前仍重新校验契约，不重放结果未知的非幂等调用。
- 初始化失败保存检查点时，保留原需求、计划、工作区基线、指纹及结果未知的调用。恢复时，完整且未变化的工作区保留有效源码证据与真实测试回执；工作区变化、指纹不完整或有未知写入时仍重新检查与测试。
- 当前 epoch、revision 下成功且完整的源码读取，可用于后续架构阶段，不再仅因发生在需求理解之前而被拒绝。读取缓存直接返回已校验的原范围内容；失败、截断、过期及不支持的证据仍不能用于验收。
- 补丁按实际内容修正冗余 hunk 行数和新文件坐标，保留原文件坐标与内容。检查全部目标的原始内容后才应用，拒绝偏移匹配。格式错误可利用当前源码和计划直接纠正重试；内容冲突只提示读取受影响范围，不要求重建计划或反复读取全部文件。
- 自动独立模型审核继续关闭；真实局部测试、集成测试及逐项需求验收继续保留。
