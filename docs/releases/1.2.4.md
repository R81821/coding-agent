# Harness Agent 1.2.4

修复安装版连接已有开发版后台、跳过当前模型配置而导致运行无法选择模型的问题。

- 桌面每次启动生成独立后台实例 ID，同时传给后台并用于所有请求。旧的默认开发后台不能再响应安装版请求。
- 保存设置后的后台重启仍使用本次桌面实例的地址，并重新读取保存的模型配置。CLI 独立后台保留原默认地址。
- 后台健康信息新增 providerIds，只报告加载的服务商标识，不包含凭据。
- 路由失败时分别说明无服务商、Profile 未授权、模型不可用、能力不支持、上下文容量不足和预算不足。

验证包含路由筛选和实例 ID 回归测试，以及两个真实后台在独立地址加载不同服务商配置的本地集成测试。未发起收费模型请求。
