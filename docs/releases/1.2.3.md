# Harness Agent 1.2.3

修复会话历史与项目平级展示的问题。

原因：1.2.2 已恢复持久化历史，但侧栏把“项目”和“会话历史”渲染成两个独立区块。每条会话虽然显示了项目名，结构和缩进上并不属于对应项目。

- 按标准化后的 `workspacePath` 对会话分组，并渲染为“项目 → 会话”父子层级。
- Windows 路径的大小写、斜杠方向和末尾斜杠差异会合并到同一项目。
- 当前项目排在首位；没有历史的当前项目仍显示，并提示发送任务后自动保存。
- 会话子项只显示标题和状态，项目名称由父节点统一表达。
- 点击项目节点展开或收起会话；点击子会话恢复对应项目的历史内容。

同时包含 Windows 开发模式的 preload 路径、后台启动及 TypeScript 配置修正。

验证：类型检查、lint、27 个测试文件的 97 项测试、生产构建和隔离 Electron 界面测试通过。界面测试覆盖两个项目的嵌套关系、新建保留分组、跨项目历史恢复、发送新任务及页面重新加载。
