# 内置浏览器截图

浏览器标题栏的相机按钮截取当前标签页的可视区域，打开 PNG 预览，并提供“保存 PNG”。加载期间或正在截图时按钮禁用；切换网页、对话或关闭预览会释放图片资源，过期截图不会显示在新页面中。

Agent 通过现有 `browser` 工具调用截图，按对话隔离标签页：

```json
{ "action": "screenshot", "tabId": "从 tabs 获取的标签 ID" }
```

整页截图使用 `fullPage: true`，不改变页面的可视区域尺寸。工具返回网址、标题、像素尺寸、截图范围和捕获时间；像素单独存入加密附件，交给当前已授权的视觉模型。工具事件、证据和恢复转录只保存附件引用，不写入 Base64 正文，也不修改项目文件。

非视觉模型只收到截图回执和明确的视觉能力提示，不能凭回执声称检查了画面。恢复后切换服务商也不能扩大原截图的服务商授权。网页文字和截图内文字均为不可信资料，不授予工具权限。

空图、网页在截图期间跳转、取消和超时均返回可重试错误。单图限制为 12 MiB、最长边 16384 像素和 32 Mi 像素；超过限制可截取当前可视区域。

验证覆盖真实 Electron 离屏页面中的生产截图方法和 Canvas 像素、桌面通信管道、加密附件、四种供应商协议、恢复转录、非视觉降级，以及按钮预览的异步与资源清理。原生测试使用离屏页面；从未显示的普通窗口可能缺少绘制表面，截图回退仍不可用时会返回可重试错误。
